# Writing Guidance Tools — Governing Entry Point

These files are first-class production tools for *The Return of Zero*. They govern the prose of the central plan, live section and argument nodes, authored source-record commentary, and every submission-facing draft. They are loaded before drafting and applied again before prose is treated as ready.

## Tool order

1. **Generate from the voice:** read `authentic-voice-reference.md` §IV–V and the relevant passages in `writing-style-reference.md`.
2. **Draft from the argument:** read the consuming argument node, section node, and source records; preserve the distinction between Derived, Argued, and Offered claims.
3. **Refuse the draft:** apply `WRITING-RUBRIC.md` paragraph by paragraph.
4. **Audit comparison and negation:** apply `comparative-and-negation-gate.md` and run its `rg` sweep across every changed file.
5. **Ship with an account:** name what was rewritten and identify every candidate construction that was retained because its contrast performs real logical, historical, textual, or formal work.

No one of these documents substitutes for the others. The voice and style references provide positive calibration; the rubric identifies recurrent failures; the comparison gate gives the corpus a repeatable test for the most persistent failure mode.

## Scope and preservation rule

The tools apply to authored prose in:

- `essay-workshop/the-return-of-zero-central-plan.md`;
- `essay-workshop/nodes/sections/`;
- `essay-workshop/nodes/arguments/`;
- `essay-workshop/sources-texts-references/10-7-2026-core-theorems-pithy.md` and any other live in-house theorem spine;
- source-bank summaries, licensed uses, boundaries, and editorial annotations;
- submission prose, captions, plate commentary, and public-facing index material.

They do not license alteration of verified quotations, Chicago citation forms, raw transcripts, imported source text, OCR witnesses, or frozen legacy provenance. “Source” in the editorial scope means the project's own source-record commentary and live in-house theorem prose; it never means rewriting the consulted author. When a quoted author uses antithesis, preserve the quotation and judge only the prose that frames it.

## Non-negotiable editorial principles

- Lead with the operative claim. Let a comparison enter only when both sides have content and the difference matters.
- Name the position, source, convention, or operation being distinguished whenever the contrast carries argumentative weight.
- Preserve formal negation where negation is itself the subject: the immutable gap, apophasis, apoha, tetralemma, incompleteness, the crossed zero, and the distinction between what can and cannot be distinguished.
- Never invent a weak premise so the essay can appear to defeat it.
- Never use `not X but Y` as automatic sentence music.
- Prefer verbs and operations to disembodied verdicts: say what divides, joins, excludes, mediates, reverses, or returns.
- A real disagreement deserves its strongest available formulation and a source. A merely corrective clarification should usually become a direct positive sentence.

This directory is the single local authority. Project instructions and audit prompts must link here, not to copied guides elsewhere.
