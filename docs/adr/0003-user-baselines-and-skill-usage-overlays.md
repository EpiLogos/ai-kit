# Keep user baselines and additive skill guidance separate from sources

AIKit will complete its already-modelled global scope as a persistent User
Baseline Profile, and will compile scoped Skill Usage Overlays into Effective
Skills during generation. Overlays are additive, provenance-labelled guidance:
they may extend discovery descriptions and append authoritative contextual
instructions, but they cannot rewrite upstream frontmatter policy, payload
files, trust, or source identity. A higher scope may reset inherited overlays
before adding its own, preserving project reproducibility without turning
ordinary guidance into a source fork. This keeps personal orientation durable
across upstream updates while reserving wrappers or derived skills for genuine
contract or invocation-policy changes.
